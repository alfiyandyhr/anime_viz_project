About / Data

The Full Catalogue is the loaded popularity-sorted AniList sample, not every anime. Seasons and films are separate entries. Popularity counts AniList list users; scores use a 0–100 scale. Missing values remain unknown.

Filters and shortlist are independent of Dust & Magnet. Select a row for secondary metadata and credits.

Source: AniList

Movie uses the same archived TMDB sample, ratings, and popularity values as Dust & Magnet. Scores use a 0–10 scale. Popularity rank sorts the full sample by the archived popularity values and stays fixed when you sort or filter the table.

Actor counts use up to five sampled cast members per film. Writer counts use TMDB’s Writing department credits. Select a row to see the synopsis and credits.
